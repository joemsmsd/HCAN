# HCAN

Code for **HCAN: Hypergraph-based Cross-Attention Network for Irregular Multivariate Time Series Forecasting**.

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
bash scripts/HCAN/USHCN.sh
bash scripts/HCAN/MIMIC_III.sh
bash scripts/HCAN/MIMIC_IV.sh
bash scripts/HCAN/P12.sh
bash scripts/HCAN/HumanActivity.sh
```

## Datasets

Place datasets in `storage/datasets/`.
